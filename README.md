# google-docs-background

Chrome extension for adding a custom background image to the Google Docs word editor.

## Installing and running the extension

To use the extension, download this repository to your local machine and then, in your Chrome browser, go to: chrome://extensions/

On the top right of the page, enable "Developer mode"

Select "Load unpacked" and select the repository.

You can then select the extension from your available extensions and input a custom image URL. You can also select the background image opacity and choose between background image modes.
